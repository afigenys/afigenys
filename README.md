# @afigenys

Технический специалист. Практический опыт в аппаратной диагностике, сборке ПК, обслуживании операционных систем и прикладном скриптинге (PowerShell, Python).

---

### С чем работаю:
* **ПК и аппаратная часть:** сборка системных блоков с нуля, андервольтинг CPU/GPU (оптимизация температур и уровня шума), аппаратный аудит накопителей (SMART) и батарей ноутбуков.
* **Windows (PowerShell / Batch):** оптимизация ОС под ограниченные аппаратные ресурсы, управление реестром, службами и дисковой подсистемой.
* **Python:** разработка прикладных парсеров данных (Playwright) с Telegram-оповещениями под конкретные задачи.
* **Мобильные устройства:** программное восстановление Android-смартфонов (прошивка, Fastboot, Recovery, раскирпичивание).
* **Сети:** физический монтаж и обжимка кабелей витой пары (RJ-45), базовое конфигурирование сетевого оборудования.
